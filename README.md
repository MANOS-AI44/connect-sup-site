# Connect Sup — site de téléchargement

Site statique officiel de téléchargement de l’application Android Connect Sup.

Version publiée : **1.2.3** (`versionCode 9`).

Cette version unifie le stockage des syntaxes, migre automatiquement les réglages des versions précédentes et vérifie la sauvegarde avant de quitter les paramètres.

Le site est configuré pour un déploiement direct sur Render depuis la racine du dépôt.
